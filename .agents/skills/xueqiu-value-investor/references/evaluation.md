# 雪球线索价值投资评分

对每个候选项按 0–2 分记录，并同时写出一条最强反证。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 生意可理解性 | 无法解释利润来源 | 大致理解 | 能说清客户、定价与单位经济 |
| 护城河 | 主要靠景气/补贴 | 有局部优势 | 品牌、成本、网络或转换成本可验证 |
| 管理层与治理 | 存疑 | 证据不足 | 诚信、能力、股东导向有记录支持 |
| 财务质量 | 现金流/负债恶化 | 周期波动 | ROIC/现金流/资产负债表稳健 |
| 成长可持续性 | 依赖叙事 | 有催化但不确定 | 长期需求与份额逻辑可验证 |
| 估值与安全边际 | 无锚或明显昂贵 | 合理价附近 | 多方法估值均显示至少 25% 安全边际 |
| 能力圈 | 无法跟踪 | 可补课 | 已有研究框架和持续数据源 |

## 决策阈值

- 0–5：回避。
- 6–9：研究。
- 10–12：观察。
- 13–14：完成一手数据复核后才可列为候选买入。

任何治理红旗、财务造假疑点或无法解释的高杠杆，均覆盖总分并降为回避。
